All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses date-based entries since it is a continuously updated personal site rather than a versioned package release.

## [1.0.0] - Initial Release

### Added
- Responsive single-page portfolio with Home, About, Skills, Projects, and Contact sections
- Sticky, accessible navigation with mobile menu toggle
- Animated canvas-based DNA double-helix visual in the hero section
- Scroll-reveal animations for section content
- Auto-scrolling skills/technologies marquee
- Project showcase cards linking to live GitHub repositories (BioDNA Inspector, VITALOS, Student Management System)
- Copy-to-clipboard contact email with toast notifications
- Back-to-top navigation control
- Self-hosted Inter and Cormorant Garamond fonts
