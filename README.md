# Paramdeep Singh — Personal Portfolio

A dependency-free personal research portfolio built with **HTML + CSS + vanilla JavaScript only**.

## Structure
- `index.html` — complete website markup/content
- `styles.css` — responsive visual system
- `script.js` — navigation, active section highlighting, reveal animations, year
- `public/profile.png` — profile photo
- `public/Paramdeep-Singh-CV.pdf` — CV used by Download CV
- `public/certificates/` — certificate image placeholders

## Certificate images
Replace these files with your actual certificate images:
- `certificate-01.jpg`
- `certificate-02.jpg`
- `certificate-03.jpg`
- `certificate-04.jpg`
- `certificate-05.jpg`
- `certificate-06.jpg`

JPG, PNG and WebP are supported; if you use a different extension, update the corresponding `src` in `index.html`.

## Run locally
No npm, Node.js or build step is required.

Option 1: open `index.html` directly in a browser.

Option 2: serve the folder with any static server, e.g. VS Code Live Server.

## Deploy
Upload the folder to any static hosting provider such as GitHub Pages, Netlify or Vercel. No backend is required.
